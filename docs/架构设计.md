# 系统架构详解

## 一、请求流程

```
1. 用户在浏览器操作（登录/上传/下载等）
2. 浏览器发送 HTTP 请求到 Nginx (192.168.226.128:80)
3. Nginx 根据 URL 路径分发：
   - / → 静态文件 (index.html)
   - /hello/ → 静态文件 (yundisk/index.html)
   - /login → FastCGI (127.0.0.1:9001)
   - /register → FastCGI (127.0.0.1:9000)
   - /upload → FastCGI (127.0.0.1:9999)
   - /download → FastCGI (127.0.0.1:9003)
   - /filelist → FastCGI (127.0.0.1:9004)
   - /delete → FastCGI (127.0.0.1:9005)
   - /share → FastCGI (127.0.0.1:9006)
4. FastCGI 程序处理业务逻辑，操作 MySQL/Redis/FastDFS
5. 返回 JSON 响应或文件流
```

## 三、Nginx 配置详解

### 3.1 完整配置

```nginx
user s;
worker_processes  1;

events {
    worker_connections  1024;
}

http {
    include       mime.types;
    default_type  application/octet-stream;
    sendfile        on;
    keepalive_timeout  65;

    # HTTP 服务器
    server {
        listen       80;
        server_name  localhost;

        # 前端静态页面
        location / {
            root   /usr/local/nginx/zyFile2;
            index  index.html index.htm;
        }

        # 云盘前端页面
        location /hello/ {
            alias /usr/local/nginx/yundisk/;
            index index.html;
        }

        location /upload-page/ {
            alias /usr/local/nginx/yundisk/;
            index index.html;
        }

        # ===== FastCGI 接口路由 =====

        # 注册
        location /register {
            fastcgi_pass 127.0.0.1:9000;
            include fastcgi.conf;
        }

        # 登录
        location /login {
            fastcgi_pass 127.0.0.1:9001;
            fastcgi_param REQUEST_METHOD $request_method;
            fastcgi_param CONTENT_LENGTH $content_length;
            fastcgi_param CONTENT_TYPE $content_type;
            include fastcgi_params;
        }

        # 文件上传（支持大文件）
        location /upload {
            fastcgi_pass 127.0.0.1:9999;
            fastcgi_param REQUEST_METHOD $request_method;
            fastcgi_param CONTENT_TYPE $content_type;
            fastcgi_param CONTENT_LENGTH $content_length;
            fastcgi_param HTTP_X_FORWARDED_FOR $http_x_forwarded_for;
            include fastcgi_params;
            client_max_body_size 10240m;  # 支持最大 10GB
        }

        # 文件下载
        location /download {
            fastcgi_pass 127.0.0.1:9003;
            include fastcgi_params;
        }

        # 文件列表
        location /filelist {
            fastcgi_pass 127.0.0.1:9004;
            include fastcgi_params;
        }

        # 文件删除
        location /delete {
            fastcgi_pass 127.0.0.1:9005;
            include fastcgi_params;
        }

        # 文件分享
        location /share {
            fastcgi_pass 127.0.0.1:9006;
            include fastcgi_params;
        }

        # FastDFS 文件访问
        location ~/group[0-9]/M00 {
            ngx_fastdfs_module;
        }

        error_page   500 502 503 504  /50x.html;
        location = /50x.html {
            root html;
        }
    }
}
```

## 四、FastCGI 程序架构

### 4.1 公共头文件 fcgi_common.h

所有 7 个 FastCGI 程序共享同一个公共头文件，避免重复代码：

```c
// ===== 数据库 =====
MYSQL* connect_db();                    // 连接 MySQL

// ===== 安全 =====
void md5_hash(const char *input, char *output);  // MD5 哈希
void escape_string(MYSQL *conn, const char *input, char *output, int max_len);  // SQL 转义

// ===== JSON 解析 =====
char* json_get_string(const char *json, const char *key);  // 提取字符串
int json_get_int(const char *json, const char *key, int default_val);  // 提取整数

// ===== HTTP 请求 =====
char* read_post_data(int max_len);      // 读取 POST body
char* get_query_param(const char *param_name);  // 提取 URL 参数

// ===== Multipart 表单 =====
char* multipart_get_field(const char *data, const char *field_name);    // 提取字段值
char* multipart_get_filename(const char *data);                          // 提取文件名
char* multipart_get_attr(const char *data, const char *attr_name);      // 提取扩展属性

// ===== 工具 =====
void generate_token(char *token, int len);  // 生成随机 token
```

### 4.2 各程序职责

| 程序 | 端口 | 源码 | 功能 |
|------|------|------|------|
| `login_fcgi` | 9001 | login_fcgi_new.c | 验证用户名密码，返回用户信息 |
| `register_fcgi` | 9000 | register_fcgi_new.c | 注册新用户，重复检测 |
| `uploadFile_fcgi` | 9999 | upload_fcgi_new.c | 解析 multipart，保存文件，写入数据库 |
| `download_fcgi` | 9003 | download_fcgi_new.c | 查询文件信息，返回文件流 |
| `filelist_fcgi` | 9004 | filelist_fcgi_new.c | 查询用户文件列表 |
| `delete_fcgi` | 9005 | delete_fcgi_new.c | 删除文件记录 |
| `share_fcgi` | 9006 | share_fcgi_new.c | 生成分享链接 |

### 4.3 请求处理流程（以上传为例）

```
1. Nginx 收到 POST /upload 请求
2. Nginx 通过 FastCGI 协议转发到 127.0.0.1:9999
3. uploadFile_fcgi 接收请求：
   a. 读取 POST body (read_post_data)
   b. 解析 multipart 表单：
      - 提取 "user" 字段 → 用户名
      - 提取 "file" 字段 → 文件名、md5、size
      - 提取文件二进制内容
   c. 保存文件到 /home/s/uploads/
   d. 写入 MySQL files 表
   e. 返回 JSON 响应
4. Nginx 将响应转发给浏览器
```

## 五、数据库设计

### 5.1 ER 关系图

```

├──────────────┤─────────┼──────────────┤
```

### 5.2 users 表（用户表）

```sql
CREATE TABLE users (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    username    VARCHAR(50) UNIQUE NOT NULL,     -- 用户名（唯一索引）
    password    VARCHAR(32) NOT NULL,            -- MD5 哈希密码（32位十六进制）
    nickname    VARCHAR(50),                      -- 昵称
    email       VARCHAR(100),                     -- 邮箱
    phone       VARCHAR(20),                      -- 手机号
    token       VARCHAR(64),                      -- 登录 token
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,  -- 注册时间
    last_login  DATETIME                           -- 最后登录时间
);
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 用户唯一 ID |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 登录用户名 |
| password | VARCHAR(32) | NOT NULL | MD5(username + password) 的十六进制字符串 |
| nickname | VARCHAR(50) | — | 显示昵称 |
| email | VARCHAR(100) | — | 联系邮箱 |
| phone | VARCHAR(20) | — | 手机号码 |
| token | VARCHAR(64) | — | 登录凭证，格式：{user_id}_{timestamp} |
| created_at | DATETIME | DEFAULT NOW() | 账号创建时间 |
| last_login | DATETIME | — | 最后登录时间 |

### 5.3 files 表（文件表）

```sql
CREATE TABLE files (
    id              INT AUTO_INCREMENT PRIMARY KEY,
    user_id         INT NOT NULL,                -- 所属用户 ID
    filename        VARCHAR(255) NOT NULL,       -- 原始文件名
    file_id         VARCHAR(128) NOT NULL,       -- 存储路径或 FastDFS ID
    file_size       BIGINT,                       -- 文件大小（字节）
    file_md5        VARCHAR(32),                  -- 文件内容 MD5
    upload_time     DATETIME DEFAULT CURRENT_TIMESTAMP,
    download_count  INT DEFAULT 0,               -- 累计下载次数
    folder_id       INT DEFAULT 0,               -- 所属文件夹（预留）
    share_token     VARCHAR(64),                  -- 分享 token
    share_expire    DATETIME,                     -- 分享过期时间
    is_public       TINYINT DEFAULT 0,            -- 是否公开（预留）
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | PK, AUTO_INCREMENT | 文件记录唯一 ID |
| user_id | INT | FK → users.id | 文件所有者 |
| filename | VARCHAR(255) | NOT NULL | 用户上传时的原始文件名 |
| file_id | VARCHAR(128) | NOT NULL | 本地存储路径（/home/s/uploads/xxx）或 FastDFS ID |
| file_size | BIGINT | — | 文件字节数 |
| file_md5 | VARCHAR(32) | — | 文件内容的 MD5 哈希 |
| upload_time | DATETIME | DEFAULT NOW() | 上传时间 |
| download_count | INT | DEFAULT 0 | 被下载的次数 |
| folder_id | INT | DEFAULT 0 | 文件夹分类（预留扩展） |
| share_token | VARCHAR(64) | — | 分享链接中的 token |
| share_expire | DATETIME | — | 分享链接过期时间 |
| is_public | TINYINT | DEFAULT 0 | 是否公开访问（预留扩展） |

## 六、安全设计

### 6.1 密码存储

```
明文密码 "123456"
    ↓ MD5 哈希
"e10adc3949ba59abbe56e057f20f883e"  (32位十六进制)
    ↓ 存入数据库
users.password 字段
```

### 6.2 SQL 注入防护

所有用户输入经过 `mysql_real_escape_string()` 转义：

```c
char esc_user[256];
escape_string(conn, username, esc_user, sizeof(esc_user));
// 然后使用 esc_user 构建 SQL 查询
```

### 6.3 输入验证

- 用户名：3-16 位字母数字下划线
- 密码：至少 6 位
- 文件大小：限制 10GB（client_max_body_size）
- 文件路径：禁止路径穿越（..）
