## 当前项目事实边界

- 客户端包括 Qt桌面端和 Web端。
- 宿主机 `8080` 映射到容器 Nginx的 `80` 端口。
- Nginx把请求转发到7个 C/FastCGI程序，每个配置4个工作进程。
- MySQL保存用户、Token和文件元数据。
- 文件优先保存到 FastDFS，失败时回退到本地持久化目录。
- Redis会启动，但当前没有接入 Token或业务缓存。
- Token使用 OpenSSL安全随机数生成，但仍保存在 MySQL中，缺少完整过期、刷新和撤销机制。
- 用户密码仍使用 MD5，不能描述为安全密码方案。
- 当前是单容器、单 Tracker、单 Storage的开发/演示部署，不是高可用分布式集群。
- 当前上传请求体上限为10 MiB，不支持分片上传和断点续传。
- 历史功能回归覆盖23项；历史压测只代表本机 Docker Desktop短时轻量结果。

## 面试回答原则

回答一个项目问题时，优先使用下面的结构：

```text
场景或问题
  → 当前实现
  → 为什么这样做
  → 如何验证
  → 当前不足和改进方案
```

如果项目基于课程或已有样例，应明确说“在原有项目基础上进行二次开发和系统性修复”，不要声称全部从零完成。
